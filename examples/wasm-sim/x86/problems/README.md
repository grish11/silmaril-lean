# x86 functions posed as Wasm problems (generated)

`wasm-sim problems [--check]` from `../tests/contracts.toml` (+ `funcs.S`, `cfuncs.c`).
The contract vocabulary: `(reg r)` = location `r` after the call, `(old t)` = `t` at entry,
`(memN a)` = the N-bit little-endian value at guest address `a` in the window.

* `closed/<f>.wat`: one closed module per contract. Every GPR and flag is a parameter of the
  exported wrapper `<f>`; memory is the imported `env.mem` (page 0 = the guest window
  W = [0x100000, 0x110000), page 1 scratch); `nd.undef`/`sys.syscall` are imports. The wrapper
  loads every GPR and flag from its parameters, sets rip to the entry, reads the return address
  ret := [rsp], snapshots the window, runs the P-calls translation of the machine code, and then
  traps unless rip = ret, rsp = rsp0 + 8, rbx rbp r12-r15 hold their entry values, and no window
  byte outside the footprint changed. `;; @requires` = ABI entry alignment, rsp in
  [W + 0x1000, W + 0x10000 - 8], and the contract precondition; `;; @ensures` = the contract
  postcondition; `;; @footprint` = [rsp - 0x1000, rsp) plus the contract's ranges.
* `split/<f>/`: the same problem decomposed per x86 function: `<g>.wat` imports the shared
  simulator `../sim.wat` (module `sim`) and its callees (`<callee>.<callee>`, with
  `;; @assume <callee> (=> requires ensures)`), `pieces/<g>.json` (schema
  `silmaril.wasm-sim.piece.v0`, kind `assume-guarantee`), `link.json` (callee-first instantiation
  order). Linking the pieces is the composition. Mutual recursion is rejected.
* `max2.wat`: an earlier problem format (local memory, SysV wrapper over `rdi`, `rsi`), kept
  because `Silmaril.Sim.X86.Max2` quotes it verbatim. A frozen artifact: it was generated by
  `wasm-sim pcalls --mode problem`, which has since been removed, so it cannot be regenerated;
  edit it only together with the quotation.
* `legacy/`: other modules in that earlier format, kept for comparison only.

`--check` runs each closed problem and each linked split from random entry states against
the P-mem simulator and checks the contract on every concrete (entry, exit) pair with z3.
This is testing, not proof.

## Correspondence with `FnContract.Spec.Total`

Let C = (R, E, F) be a contract (requires, ensures, footprint) and P(C) the Wasm problem: for
all parameters p (16 GPRs, 7 flags), all contents M of `env.mem` and all behaviours of the
`nd`/`sys` imports, if `@requires` holds then the wrapper returns normally (no trap) and
`@ensures` holds of (p, M, the final simulator state, the final window).

Take the x86 specification S_C (`Silmaril/Machine/X86/FnContract/Defs.lean`) with
`entry s` := the function's code bytes at 0x400000, rip = entry, the window W disjoint from the
code, rsp in [W + 0x1000, W + 0x10000 - 8], and R; `footprint s` := [rsp - 0x1000, rsp) and F;
`post` := E. The parts of `Spec.Result` correspond as follows:

| `FnContract` | closed problem |
|---|---|
| `abi.pc` | rip = ret check (ret = `Open.retOf` = [rsp] at entry) |
| `abi.stack` | rsp = rsp0 + 8 check |
| `abi.calleeSaved` | the six callee-saved register checks |
| `frame` (`WritesWithin` footprint) | window check; any access outside W traps |
| `post` | `@ensures` |
| `silent` | holds trivially (only core state and memory change) |
| `AbiEntry.aligned` | the alignment conjunct of `@requires` |
| `AbiEntry.returnAddress` | holds for every M (ret is read from M) |
| `∀ s` | ∀ p, M (memory outside W cannot be read without trapping) |
| `∃ t, Reaches` | normal termination (the run is deterministic given the imports) |

Hence P(C) implies `Spec.Total Open9.isa S_C`, given (a) soundness of the simulator methods
used, (b) correctness of the P-calls translation, and (c) that `nd.undef` covers Open9's choices
for undefined flags (P(C) quantifies over all import behaviours, so every Open9 choice is one of
them). (b) is tested (P-calls against P-mem lockstep), not proved, for these generated modules;
the proved route is the certified translator `Silmaril.Sim.X86.G` (see `docs/wasm-sim-abi.md`).
Conversely, `Spec.Total` implies P(C) on this fragment when the simulator is complete for the
executed instructions, E does not depend on undefined flag values, and the run stays in W.

Remaining differences from `FnContract`: footprints and addresses are restricted to the 64 KiB
window, and syscalls are an opaque import.
