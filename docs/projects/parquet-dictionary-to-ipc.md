# Checked flat PLAIN and dictionary INT32 Parquet to Arrow IPC streams

`Parquet.Snapshot.FlatInt32Dictionary.ToIpc.convert` takes an immutable
Parquet file, a complete ordered Arrow field list, and separate reader and
writer limits. It checks the source byte cap and the footer, then derives
the exact field list from the checked physical schema. Required INT32
fields become nonnullable Arrow INT32, and optional fields become nullable
Arrow INT32. The expected and derived lists must agree in type, width,
order, name, and nullability before any payload is decoded.

The existing dictionary-aware snapshot binder supplies every indexed
row-group read. The decoder follows the existing flat, uncompressed
PLAIN and dictionary INT32 profile for Data Page V1 and V2 without CRC.
The IPC stream contains one primitive INT32 batch per successfully
exhausted source group in footer order. The existing stream writer emits
schema, record batches, and explicit EOS. Dictionary values are resolved
by the source decoder into primitive values. [Snapshot profile](parquet-dictionary-snapshot.md)

An admitted zero-row group contributes one empty RecordBatch. An admitted
file with no groups gives a schema-only stream. The fixture includes both
cases. A separate PyArrow-generated zero-row group has column page offsets
of zero and is rejected by the checked footer with `pageInterval`.

Conversion materializes the groups before emitting. The first failed
group returns the exact indexed cause and no completed IPC wire. The
abstract source events still retain the already-read prefix. The
`convert_first_error` law relates these outcomes.
`convert_readback` gives exact fields, each successful footer-indexed
read, per-batch row counts, and ordered signed INT32 or null values
through wire readback, including their flattened order.
[Theorem header](../../Silmaril/Formats/Parquet/Snapshot/FlatInt32Dictionary/ToIpc/Thms.lean)

## Independent checks

CPython 3.13.5, PyArrow 26.0.1, and Apache Thrift 0.25.0 check the pinned
input files and independent IPC reference. The mixed source has two
eight-row groups. Thrift checks required INT32 V2 data pages with
PLAIN encoding ID 0 and optional INT32 chunks with PLAIN dictionaries
and RLE_DICTIONARY data encoding ID 8. The late control changes the
second group's dictionary index width to 33. PyArrow reads group 0
and rejects group 1. Lean checks the exact group, column, and decoder
error and the retained abstract prefix. The CRC and Snappy controls
are genuine wire fixtures from the source reader's corpus and are
rejected at their original typed stages.

PyArrow independently verifies the exact fields, batch counts, and
nullable rows of the emitted mixed, schema-only, and zero-row-group
streams. It also reads the valid zero-row Parquet fixture produced by the
existing Lean writer. The oracle writes generated bytes to its output
directory. [Fixture hashes](../../scripts/parquet-dictionary-to-ipc-oracle/sha256.json)

```sh
lake build --wfail +Silmaril.Formats.Parquet.Snapshot.FlatInt32Dictionary.ToIpc.Checks
lake env lean -DautoImplicit=false -DwarningAsError=true Silmaril/Formats/Parquet/Snapshot/FlatInt32Dictionary/ToIpc/Checks.lean
python3.13 scripts/parquet-dictionary-to-ipc-oracle/check.py --out /tmp/parquet-dictionary-to-ipc
```
