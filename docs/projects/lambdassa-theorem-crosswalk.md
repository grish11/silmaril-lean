## Conventional φ nodes and block arguments

The thesis's `denote_convert_cfg` proves whole-program equality in a lawful Elgot monad with absorbing failure for a phi-free mutable source and a store defined on the finite interface of source variables. It covers backedges and compares generated predecessor-indexed φ-SSA with the source CFG's monadic denotation. `normalizedEquiv` and `normalizedEquiv_denote` carry the result to block arguments under normalization. The thesis block-argument denotation is defined through `toPhi`, so its transfer theorem uses exact reconstruction. The audit built the capstones on the thesis Lean pin and ran `#print axioms`, with only `propext`, `Classical.choice` and `Quot.sound` in their axiom closures. Transpose predecessor rows into argument vectors while checking unique block labels and parameter destinations, target resolution, edge arities and canonical row order.
