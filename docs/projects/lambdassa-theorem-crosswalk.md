## Conventional φ nodes and block arguments

The thesis's `denote_convert_cfg` proves whole-program equality in a lawful Elgot monad with absorbing failure for a phi-free mutable source and a store defined on the finite interface of source variables. It covers backedges and compares generated predecessor-indexed φ-SSA with the source CFG's monadic denotation. `normalizedEquiv` and `normalizedEquiv_denote` carry the result to block arguments under normalization. The thesis block-argument denotation is defined through `toPhi`, so its transfer theorem uses exact reconstruction. The capstones build on the thesis Lean pin, with only `propext`, `Classical.choice` and `Quot.sound` in their axiom closures. [Conversion theorem](https://github.com/imbrem/thesis/blob/69a8126f2d3eb6d32050e0bd9511251b33dbcea7/formalization/thesis/Isotope/TAC/Densem/MonadicValid.lean#L684-L696) · [Syntax equivalence](https://github.com/imbrem/thesis/blob/69a8126f2d3eb6d32050e0bd9511251b33dbcea7/formalization/thesis/Isotope/TAC/Bridge/PhiBBA.lean#L1201) · [Block-argument semantics](https://github.com/imbrem/thesis/blob/69a8126f2d3eb6d32050e0bd9511251b33dbcea7/formalization/thesis/Isotope/TAC/Densem/Bridge/PhiBBA.lean#L79-L116)

Silmaril already has a whole-run Elgot theorem for cyclic named RTL versioning to block-local packets, with a `PairLawful` model. It also has a partial checked adapter from that generated representation to indexed Isotope tables, and reaching-version/φ placement theorems for acyclic quad CFGs. A first port can take a normalized φ CFG as input. Transpose predecessor rows into argument vectors while checking unique block labels and parameter destinations, target resolution, edge arities and canonical row order. The source theorem also requires unique `(source, target)` edge keys for generated graphs. Split parallel edges or extend the source convention explicitly before claiming coverage of edge-occurrence columns. Use an explicit return exit, matching primitive interpretations and failure behavior, and a variable/packet relation. Prove simultaneous φ assignment agrees with lexical block entry, then lift the entry and step square through the existing Elgot uniformity result. The resulting target is equality of the complete-Elgot return denotations for accepted normalized graphs. Typed Isotope admission can use the existing `NamedFlat` checker afterward.
