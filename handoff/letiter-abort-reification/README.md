# Lean handoff for the LetIter abort-sequencing audit

This branch is for read-only review. The exact repository base is `395126f12192ff714893b94a5bc98571e34f7f11`.

```sh
lake build --wfail +Silmaril.SSA.Isotope.LetIter.Categorical.Empty.Thms +Silmaril.SSA.Isotope.Bridge.Packing.Thms
lake env lean -DwarningAsError=true handoff/letiter-abort-reification/AbortReification.lean
```

The prototype defines `AbortSequenced` as the composition congruence generated by explicitly sequencing an empty scrutinee. It proves `packed_abort_seq` and `reify_abort_seq` with an arbitrary bound context and no free variables. The latter assumes reification of the scrutinee in the separate hom quotient. The derivation `reify_effectful_closed_abort` verifies the direct abort side of the native counterexample in this extension. The replay includes transitive axiom checks.
